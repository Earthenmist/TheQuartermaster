# The Quartermaster — 2.0.4-Release

Changes since public release 2.0.3.

## Changes

- Updated for WoW patch 12.1.5; the superseded 12.1.0 interface is no longer listed.

## Fixes

- Fixed Lua errors in Storage and Materials on patch 12.1.5, which removed several item functions the addon used. Item categories and quality colours show again, and items whose details are still loading get their type and subtype.

## Known issues

- Existing transaction history is preserved, but older unclassified entries cannot be identified retrospectively without receipts.
