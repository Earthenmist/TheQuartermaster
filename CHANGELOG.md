# The Quartermaster — 2.0.8-Release

Changes since public release 2.0.7.

## Fixes

- With Chattynator installed, the "Time played" lines are now hidden from chat when the "Suppress /played chat message" option is on. Before this fix, Chattynator still showed them.

## Known issues

- Existing transaction history is preserved, but older unclassified entries cannot be identified retrospectively without receipts.
