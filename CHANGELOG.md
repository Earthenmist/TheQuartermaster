# The Quartermaster — 2.0.5-Release

Changes since public release 2.0.4.

## Fixes

- Fixed notification popups, such as mail expiry reminders, letting long messages run past the edges of the popup. Text now wraps and the popup grows to fit, and stacked popups no longer overlap.

## Known issues

- Existing transaction history is preserved, but older unclassified entries cannot be identified retrospectively without receipts.
