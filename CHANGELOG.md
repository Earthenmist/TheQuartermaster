# The Quartermaster — 2.0.0-Release

Changes since public release 1.0.29.

## Changes
- Redesigned interface, dashboard, grouped navigation and settings, with scan guidance and data freshness indicators.
- Added offline mailbox attachments to search and stock totals, plus mail expiry reminders.
- Added owned auction listings to Storage and Search, and item filters for slot, rarity, expansion and level.
- Expanded recipes with unlearned recipes, learning sources, ingredient quality selection and craft quantities.
- Added recipe shopping lists and combined shortages, with quantities and quality sent directly to Auctionator.
- Added profession concentration reserves, cooldown timers and Knowledge sources and specialization progress.
- Added Wealth: gold history, item earnings, auction purchases and deposits, and crafting-order income.
- Added optional character comparisons for currencies, reputations and professions.
- Expanded weekly activity guidance; added offline quest logs and Warband/personal achievement browsing.
- Reorganised account totals and completed translations across all supported languages.

## Fixes
- Retain inactive characters and previous data when character, bank or profession collection is incomplete.
- Correct character matching across realm-name formats and keep same-named guild banks on different realms separate.
- Expired offline weekly progress and lockouts no longer appear current.
- Correct reputation subgroup placement and collection count scopes.

## Known issues
- Offline information depends on the last scan; achievement collection can initially take around 90 seconds.
- Some Knowledge sources provide guidance only; mixed-quality crafting allocations need manual review.
- Some translations may need wording or layout improvements.
